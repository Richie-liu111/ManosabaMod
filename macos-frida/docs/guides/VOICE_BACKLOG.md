# 语音历史回放

> 本页内容：让角色语音可以在历史回放（backlog）中重播的原理与配置方法。
> 前置知识：[加载外部音频资源]、[本地化配置]

## 你知道吗

用 `@voice` 指令播放的角色语音，对话中会正常播放，但**无法在历史回放里重播**。而原版游戏的角色语音是可以历史回放的——因为原版用的是**自动语音（Auto Voice）**机制，而不是 `@voice` 指令。

本文解释两种语音机制的区别，并把剧本改成「可历史回放」的语音。

## 原理：为什么 `@voice` 不能历史回放

游戏基于 Naninovel 引擎。历史回放（backlog）里每一条消息的语音，来自打印指令执行时保存的 `AutoVoicePath`：

- `@voice "路径"` 是一条**独立指令**，它直接调用 `AudioManager.PlayVoice(路径)` 播放声音，但**不参与**打印消息的保存流程 → backlog 里没有这条语音 → 历史回放点不出声音。
- **自动语音**是打印指令（`@print`）自带的：当一行对话同时满足「有文本 ID」+「有角色名」时，引擎会自动解析出语音路径并播放，同时把这个路径**写进 backlog 消息** → 历史回放就能重播。

原版游戏正是这么做的：Adv 章节的对白都是「文本 ID + 自动语音」，语音文件放在 `Voice/{剧本路径}/{文本ID}`；而审判（Trial）章节用的是显式 `@voice "CommonTrial_*"`，语音文件在 `Voice/Common/CommonTrial/`——所以原版里也只有 Adv 对白的语音能历史回放。

## 自动语音怎么工作

### 语音路径 = `{剧本路径}/{文本ID}`

当 `@print` 带 `|#ID|` 且有角色名时，引擎按以下规则解析语音路径：

```
Voice/{剧本路径}/{文本ID}
```

- **剧本路径**：游戏加载剧本时用的路径（不含 `Scripts/` 前缀），例如原版 `Act01_Chapter03/Act01_Chapter03_Adv01`，二创剧本如 `1919180_02/Main_02`
- **文本 ID**：`|#ID|` 里的 ID

所以语音文件要放在 `Voice/{剧本路径}/{文本ID}.wav`（只能用 WAV，见文末「语音格式」）。

### 本地化记录必须存在

`|#ID|` 里的 ID 必须在对应的本地化文件 `Text/Scripts/{剧本路径}.txt` 里有一条记录，否则引擎解析不出语音路径。记录里用 `; > 角色: |#ID|` 标记这是一行**角色对话**（有语音）：

``` {tabindex="0"}
# Main_02_Hiro001
; > Hiro: |#Main_02_Hiro001|
; 原文（日语或其它语言）
中文翻译
```

旁白（没有角色名）不会触发自动语音，不需要 `; >` 行。

## 教程：把显式 `@voice` 改成自动语音

### 1. 改写剧本

把「一条 `@voice` 紧跟一条 `@print`」改成「一条带 `|#ID|` 的 `@print`」：

``` {tabindex="0"}
; 改前
@voice "Hiro/001"
@print "摘要：……" author:"Hiro" waitInput:true Wait:true

; 改后
@print "摘要：……"|#Main_02_Hiro001| author:"Hiro" waitInput:true Wait:true
```

`|#ID|` 紧跟文本参数之后、其它命名参数之前。

### 2. 放置语音文件

把语音文件放到 `Voice/{剧本路径}/{文本ID}` 下，文件名 = 文本 ID（不含扩展名）：

``` {tabindex="0"}
[MOD根目录]/
  ├─ Voice/
  │   └─ 1919180_02/
  │       └─ Main_02/
  │           └─ Main_02_Hiro001.wav
  ├─ Scripts/
  └─ Text/
```

### 3. 填写本地化文件

在 `Text/Scripts/{剧本路径}.txt` 中为每个 ID 添加记录：

``` {tabindex="0"}
# Main_02_Hiro001
; > Hiro: |#Main_02_Hiro001|
; 摘要：……
摘要：……
```

### 4. 测试

重启游戏进入剧本：

1. 对话时语音应照常播放（现在是自动语音在播）
2. 打开历史回放，点任意一条角色对白 → 应能重播语音

## 注意事项

- **不要同时保留 `@voice` 和 `|#ID|` 自动语音**，否则一行会播放两次
- 文本 ID 要与语音文件名完全一致（不含扩展名）
- `Text/` 下对应的 `.txt` **不能是空文件**——引擎需要里面的记录来解析语音路径
- 旁白行（无角色名）没有自动语音；需要「角色名」才能触发自动语音（`author:"角色"` 或 txt 里的 `; > 角色: |#ID|`）
- **语音格式**：以下限制针对**未打补丁的原装转换器**——macOS Frida 加载器。它只能处理 **WAV + PCM 16-bit / 44100Hz / 双声道（立体声）**，散文件音频**没有 Ogg 转换器**，磁盘上的裸 `.ogg` 加载不了（原版语音能播 ogg，是因为它们打包在游戏资源里、由 Unity 内置解码成 AudioClip；散文件走转换器，没有这条路）。采样率不是 44100 会**音高偏移**，位深不是 16-bit 或声道不是双声道的文件会**解码乱套**。**Windows bepinex 版例外**：官方 mod 用 Harmony 补丁把转换器换成了完整解码器（`ModAudioDecoder`，NVorbis 解 OGG、支持任意采样率/位深/声道的 WAV），所以装 mod 的 Windows 版不受这些限制；但一份音频若想 macOS / Windows 两端通用，仍建议用标准格式。
